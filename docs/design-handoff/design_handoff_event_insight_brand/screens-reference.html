EVT-2038 · LINE 3
AI INSIGHT
Guard interlock bypassed to keep the line running
Key finding
All three interviews describe the interlock being held closed during changeover. No one identified it as a workaround — it was described as "how we do it at shift change".
Contributing factors
Changeover target unchanged since the guard was fitted
Induction covers the guard, not the changeover exception
Supervisor sightline blocked by the new pallet stack
Recommended actions
Re-time changeover with the guard in place
Add the exception to the Line 3 induction
